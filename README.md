Routing structure:
Customers
GET /customers — returns a list of all customers

GET /customers/:id — returns a customer by ID

POST /customers — creates a new customer

PUT /customers/:id — updates a customer by ID

PATCH /customers/:id — partially updates a customer by ID

DELETE /customers/:id — deletes a customer by ID

Medications
GET /medications — returns a list of all medications

GET /medications/:id — returns a medication by ID

POST /medications — creates a new medication

PUT /medications/:id — updates a medication by ID

PATCH /medications/:id — partially updates a medication by ID

DELETE /medications/:id — deletes a medication by ID

The server runs locally at http://localhost:3000 by default.
